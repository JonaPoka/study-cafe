# Credits

Study Café uses only free, credited pixel art. Every asset keeps its original license. When you ship the game, show these credits somewhere players can find them (the demo has a Credits button).

## Environment: LPC Revised

Source: [LPC Revised (Eliza Wyatt and contributors)](https://github.com/ElizaWy/LPC)  
Licenses: CC-BY 3.0, OGA-BY 3.0 (credit required, no share-alike)

Artists of the pieces used in the demos:

BlueCarrot16, Craftpix.net 2D Game Assets, Demetrius, Eliza Wyatt, Eliza Wyatt (DeathsDarling), Hyptosis, Lanea Zimmerman, Lanea Zimmerman (Sharm), Lanea Zimmerman (aka Sharm), Richard Kettering (Jetrel), Thekingphoenix, YuriNikolai.

Per-asset credits for everything in `assets/environment/` are in the `Credits.txt` file inside each folder, plus `assets/environment/Credits.txt`.
